LLM agent runtime

An extensible agent loop with local GGUF support, persistent conversations, and permission-gated tools.

!

This Pages site is the project preview — the AI runs locally.

GitHub Pages serves static files; it cannot run the FastAPI backend or host model inference. To use chat, image generation, or the agent API, run the app on your own machine or a trusted server.

Get started

Start the app on your machine.

Python 3.11 or newer is recommended. Add provider credentials only as environment secrets.

git clone https://github.com/TheWildKaden/ArdvarkFood.git
cd ArdvarkFood
pip install -r requirements.txt
uvicorn app:app --reload
